# Styles Guide

## 作用

`src/styles` 用于放置项目的样式规范说明和可复用样式约定。当前项目的实际样式分层如下：

- [src/app/globals.css](../app/globals.css)：全局基础样式
- [src/static/home.css](../static/home.css)：首页专属样式
- 组件专属样式：放在对应组件目录内

## 放置规则

### 1. 全局样式

全局 reset、主题变量、字体、滚动条、基础动画，统一放在 [src/app/globals.css](../app/globals.css)。

适合内容：
- CSS 变量
- reset / normalize
- 全局字体和基础排版
- 公共工具类
- 全站通用动画基线

不适合内容：
- 页面专属布局
- 某个组件的专属样式
- 一次性页面视觉修饰

### 2. 页面样式

单个页面专属样式，放在页面专属样式文件里，再由页面按需导入。

当前示例：
- [首页样式](../static/home.css)

适合内容：
- 页面布局
- 页面级 Banner、区块间距
- 当前页面独有的视觉修饰

不适合内容：
- 跨页面共用样式
- 组件内部细节样式

### 3. 组件样式

组件级样式必须放在对应组件目录内，和组件实现保持同级管理。

推荐结构：
- `component-name.tsx`
- `types.ts`
- `index.ts`
- `README.md`
- `component-name.css` 或 CSS Module（如后续启用）

适合内容：
- 组件内部布局
- 组件交互状态
- 组件专属颜色、尺寸、间距

不适合内容：
- 页面级样式
- 其他组件的共用样式

## 推荐优先级

1. 先判断样式是不是全站通用
2. 如果只属于某一页面，就放页面样式层
3. 如果只属于某一个组件，就放组件目录内
4. 只有确实跨多个页面和组件复用时，才提升为公共样式

## 维护要求

- 新增页面样式时，优先单独建文件，不要把所有样式堆进全局文件。
- 新增组件样式时，必须和组件目录一起维护。
- 任何样式文件的职责变化，都要同步更新这里的说明。
- 如果样式放置规则发生变化，先更新本 README，再改代码。

- 首页样式：`src/static/home.css`
